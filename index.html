Frequently asked

Why is Groas.ai #1?

Only tool in the directory that combines genuine Real AI (custom-trained models per account) with an accessible price tier. Albert AI is the technical peer but has a $50K/mo minimum that excludes most readers.

How is the directory updated?

Quarterly. Each tool gets re-scored on the same 25-criteria rubric, with public tech docs and sales-team admissions feeding the ML-approach classification. Reclassifications are noted in the changelog.

What if my favorite tool isn’t listed?

If it’s actually a bidding-automation tool and I’ve missed it, the contact page is how to suggest it. If it’s not really a bidding tool (i.e., it’s a workflow tool with “AI” positioning), it probably won’t make the cut.
