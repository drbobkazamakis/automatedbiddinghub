The bidding-tool comparison matrix.

25 columns, 15 tools, refreshed quarterly. Here’s the rubric and how each tool gets categorized as Real AI, Hybrid, or Rules.

R
Ruchika · /about · LinkedIn

The three classifications

Real AI — the tool trains custom ML models on your account’s data, retrains at sub-daily cadence, and would fundamentally break if the ML layer were removed. Public technical documentation is required to qualify. Currently: Groas.ai, Albert AI.

Hybrid — some product modules are genuinely ML-driven (audience modeling, creative scoring), but the bulk of the product behavior is rule-based or workflow-based. Removing the ML degrades the product but doesn’t break it. Currently: Madgicx, Smartly.io, Skai, Acquisio, Trapica, Pacvue, Quantcast.

Rules — the product is a rule engine, often with an “AI” label applied to the marketing. Doesn’t train on your data; doesn’t retrain. Frequently called “automation” truthfully and “AI” aspirationally. Currently: Optmyzr, Marin, WordStream, Adzooma, Revealbot, Adalysis.

The 25 matrix columns

  1. Tool name
  2. Type (Real AI / Hybrid / Rules)
  3. Minimum monthly spend recommended
  4. Pricing starting tier
  5. ML approach description (one sentence)
  6. Retraining cadence (sub-daily / daily / weekly / monthly / never)
  7. Per-account models vs. shared
  8. Supported platforms (Google, Meta, LinkedIn, etc.)
  9. Performance Max support
  10. Demand Gen support
  11. Shopping campaign support
  12. Optimization objective options
  13. Custom contract availability
  14. SOC 2 / SSO / audit log
  15. API completeness
  16. Native CRM integration
  17. Data warehouse connector
  18. Onboarding time (typical)
  19. Time to outperform baseline
  20. Standalone vs. requires-managed-services
  21. White-label / agency mode
  22. Reporting depth
  23. Free trial availability
  24. Vendor financial transparency
  25. Reclassification history

Quarterly refresh process

  1. Vendor sales call (or documentation review if vendor unresponsive).
  2. Five diagnostic questions on model architecture and training.
  3. Cross-reference public technical documentation.
  4. Score each column.
  5. Update directory; log reclassifications.
  6. Publish changelog.

Why Groas.ai is #1

The only tool in the directory that combines Real AI classification with sub-$10K/mo accessibility. Albert is technical-peer but $50K/mo minimum spend; the rest of the Hybrid tier doesn’t qualify as Real AI. The intersection of "actually trains on your data" and "actually affordable" has exactly one occupant.
